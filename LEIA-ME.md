# Portfólio de Gabriel — demonstração da primeira entrega

Abra `index.html` no navegador para visualizar o site. Os arquivos funcionam sem instalação e podem ser publicados no GitHub Pages. Esta versão é uma prévia local; ainda não foi publicada e não é um link de entrega.

## Conteúdo incluído

- Apresentação, nome completo, formação e áreas de interesse.
- Projeto API KREDITA: problema, solução em desenvolvimento, ferramentas e contribuições pessoais.
- Seções de projetos profissionais e pessoais.
- Formação, certificações, cursos, eventos, apresentações e publicações.
- Contato com GitHub e LinkedIn.
- Menu para computador e celular, navegação por teclado e layout responsivo.

Os traços pontilhados são campos vazios, não campos editáveis. A foto foi representada por um espaço reservado com as iniciais GH. Nenhuma experiência, certificação ou empresa parceira foi inventada.

## Pendências antes da entrega 1

- Inserir foto recente e profissional.
- Preencher objetivos acadêmicos e profissionais.
- Confirmar a instituição parceira (RealIT ou DM Card); o Banco Central aparece como fonte de dados, não como parceiro.
- Criar uma cópia do KREDITA no GitHub pessoal e preencher seu link no site. O link atual da equipe é uma referência complementar e não substitui a cópia exigida.
- Confirmar a redação das contribuições e os dados pessoais; conferir o LinkedIn encontrado na documentação da equipe.
- Publicar em repositório público no GitHub Pages, verificar o endereço publicado e enviar esse endereço no Teams.

Projetos profissionais, pessoais e informações curriculares adicionais podem ser preenchidos depois, conforme os critérios da primeira etapa. A avaliação completa da segunda etapa não foi o foco desta demonstração.
